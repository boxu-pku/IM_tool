# IM Tool - 阻抗匹配分析工具

一个专业的图形化应用程序，用于冲击波物理（HEDP）中的**阻抗匹配（Impedance Matching）**分析。通过测量多层靶材料的冲击波速度，利用雨贡纽（Hugoniot）状态方程计算压力和压缩比，为冲击波实验提供准确的数据分析工具。

## 功能特性

### 核心分析功能

- **Hugoniot 曲线绘制**
  - 支持标准材料库中的多种 Hugoniot 状态方程曲线
  - 自动从材料文件加载压力、密度、压缩比、温度、内能等数据
  - 支持用户自定义参考曲线

- **雷利线（Rayleigh Line）管理**
  - 创建任意数量的雷利线，用于模拟冲击波前沿
  - 支持自定义材料参数（冲击波速度 D、初始密度 ρ₀）
  - 雷利线方程：P = ρ₀ × uₚ × D × 0.01

- **交点自动计算**
  - 自动计算所有材料曲线与雷利线的交点
  - 支持交点的可视化选择（点击图表或表格）
  - 高亮显示当前选中的交点

- **反射 Hugoniot 计算**
  - 基于选定交点计算材料的反射 Hugoniot
  - 反射公式：uₚ' = 2 × uₚ,center - uₚ
  - 自动匹配颜色并使用不同线型区分

- **压缩比实时计算**
  - 公式：CR = D / (D - uₚ)
  - 选择交点后自动显示压缩比
  - 支持多层靶的阻抗匹配分析

### 多变量可视化

支持 **8 种**不同的数据平面图表，全面展示冲击物理过程：

| 图表类型 | X 轴 | Y 轴 | 说明 |
|---------|------|------|------|
| **P-Up 图** | 粒子速度 (km/s) | 压力 (Mbar) | 主图，显示完整分析内容 |
| **P-CR 图** | 压缩比 | 压力 (Mbar) | EOS 状态方程曲线 |
| **Us-Up 图** | 粒子速度 (km/s) | 冲击波速度 (km/s) | 冲击波速度关系 |
| **P-T 图** | 温度 (eV) | 压力 (Mbar) | 压力-温度状态 |
| **rho-Up 图** | 粒子速度 (km/s) | 密度 (g/cm³) | 压缩过程 |
| **T-Up 图** | 粒子速度 (km/s) | 温度 (eV) | 温度演化 |
| **E-Up 图** | 粒子速度 (km/s) | 内能 (MJ/g) | 能量沉积 |
| **P-Us 图** | 冲击波速度 (km/s) | 压力 (Mbar) | 冲击波速度-压力 |

### 图表交互功能

- **Auto Range（自动范围）**
  - 一键缩放至数据范围
  - 自动添加 10% 边距
  - 适用于快速查看全貌

- **Inverse Axes（交换坐标轴）**
  - 交换 X/Y 轴显示
  - 适用于通用图表（Us-Up、P-T 等）
  - 便于不同视角分析

- **交互式选择**
  - 点击图表直接选择交点
  - 点击表格行选择交点
  - 图表和表格自动同步

- **出版级质量**
  - PRL（Physical Review Letters）风格
  - 衬线字体、向内刻度
  - 色盲友好配色
  - 300 DPI 高分辨率导出

### 数据格式支持

- **标准 TXT/CSV 格式**
  - 7 行注释头 + 制表符分隔数据
  - 支持必需列和可选列
  - 自动验证格式正确性

- **FEOS .hug 格式**
  - 直接读取 FEOS 程序输出
  - 自动处理单位转换
  - 支持 6 列标准输出格式

- **参考曲线 CSV 格式**
  - 简化的 CSV 格式
  - 自定义列名和单位
  - 支持部分变量（只需 Up 和 P）

## 安装说明

### 系统要求

- **操作系统**: Windows 10/11（推荐）、Linux、macOS
- **Python 版本**: 3.8 或更高版本
- **内存**: 至少 4 GB RAM
- **显示器**: 1920×1080 或更高分辨率推荐

### 安装步骤

#### 方法一：从源码安装

1. **克隆或下载项目**
```bash
git clone <repository-url>
cd IM_tool
```

2. **创建虚拟环境（推荐）**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

3. **安装依赖**
```bash
pip install -r requirements.txt
```

#### 方法二：直接运行

如果已安装 Python 和 PyQt5：

```bash
python -m im_app.main
```

或使用启动脚本：

**Windows**:
```cmd
run_app.bat
```

**Linux/macOS**:
```bash
chmod +x run_app.py
./run_app.py
```

### 依赖包列表


## 快速开始

### 第一次运行

1. **启动应用程序**
```bash
python -m im_app.main
```

2. **加载材料**
   - 在左侧"Material Library"面板中
   - 勾选想要分析的材料（如 "Aluminum (SESAME 3717)"）
   - 图表会自动显示材料的 Hugoniot 曲线

3. **创建雷利线**
   - 切换到"Rayleigh Lines"面板
   - 输入参数（或保持默认）
   - 点击"Add"按钮

4. **查找交点**
   - 切换到"Intersections"面板
   - 点击"Find Intersections"按钮
   - 所有交点会显示在表格中

5. **选择交点**
   - 点击图表中的交点标记
   - 或点击表格中的某一行
   - 选中的交点会高亮显示

6. **计算压缩比**
   - 选中交点后，压缩比会自动计算
   - 显示在交点面板中

### 典型工作流程

**阻抗匹配分析流程：**

```
1. 加载标准材料的 Hugoniot 曲线
   ↓
2. 创建雷利线（输入冲击波速度 D）
   ↓
3. 查找曲线与雷利线的交点
   ↓
4. 选择交点查看压力和粒子速度
   ↓
5. 创建反射 Hugoniot（如需要）
   ↓
6. 计算压缩比 CR = D / (D - up)
   ↓
7. 切换不同图表查看多变量关系
   ↓
8. 导出图表和数据
```

- 显示格式：`材料名称 (数据来源)`
- 勾选材料后，曲线会自动加载到所有图表

- 颜色按照预定义的色盲友好配色方案分配

   - **Material Name**: 材料名称（如 "Copper"）

3. 选择数据输入方式：
   - **From Clipboard**: 从剪贴板粘贴（推荐）

5. 点击 **Next** 预览数据
6. 点击 **Finish** 保存

```

0.5	0.05
1.0	0.12
1.5	0.22
...
```

**多列格式**（Up, Us, P, rho, compression）：
```
0.011	5.227	0.001	2.706	1.002
0.611	6.161	0.101	2.997	1.110
...
```

3. 扫描 `materials/` 文件夹
4. 自动添加新文件到 metadata
5. 删除不存在的文件条目
6. 重新加载材料列表

### 雷利线面板

**位置**: 左侧中上部

#### 功能概述

雷利线用于描述冲击波前沿的状态，是阻抗匹配分析的重要工具。雷利线方程为：

**P = ρ₀ × uₚ × D × 0.01**

其中：
- P：压力 (Mbar)
- ρ₀：初始密度 (g/cm³)
- uₚ：粒子速度 (km/s)
- D：冲击波速度 (km/s)

#### 面板组件

```
┌────────────────────────────────────┐
│  Rayleigh Lines                    │
├────────────────────────────────────┤
│ Material: [Aluminum ▼]             │
│ D (km/s): [    8.0    ]            │
│ rho0 (g/cm³): [  2.7   ] (optional)│
│                                    │
│ [Add] [Clear] [Clear All]         │
├────────────────────────────────────┤
│ ☐ Aluminum RL, D=8.00 km/s        │
│ ☑ Quartz RL, D=10.00 km/s         │
│ ...                                │
└────────────────────────────────────┘
```

#### 创建雷利线步骤

1. **选择材料**
   - 从下拉菜单选择材料
   - 或选择 "Custom" 自定义参数

2. **输入参数**
   - **D (km/s)**: 冲击波速度（必需）
   - **rho0 (g/cm³)**: 初始密度（可选，默认使用材料值）

3. **添加雷利线**
   - 点击 **Add** 按钮
   - 雷利线会显示在图表中（虚线样式）
   - 列表中会添加新条目

4. **管理雷利线**
   - 勾选列表中的条目以显示/隐藏
   - 点击 **Clear** 删除选中的雷利线
   - 点击 **Clear All** 删除所有雷利线

#### 雷利线属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| **颜色** | 与对应材料 Hugoniot 相同 | 自动分配 |
| **线型** | 虚线 (`--`) | 固定 |
| **线宽** | 0.9 | 固定 |
| **图例** | "{材料名} Rayleigh Line, D=xx km/s" | 自动生成 |

#### 使用场景

1. **单层靶分析**
   - 创建一条雷利线
   - 查找与标准材料的交点
   - 获得冲击状态（P, uₚ）

2. **多层靶分析**
   - 为每层创建雷利线
   - 追踪冲击波在层间的传播
   - 计算各层的压缩比

3. **阻抗匹配**
   - 比较不同材料的雷利线
   - 找到阻抗匹配点
   - 优化材料组合

### 交点查找面板

**位置**: 左侧中下部

#### 功能概述

自动计算所有材料 Hugoniot 曲线与雷利线的交点，是阻抗匹配分析的核心功能。交点表示冲击波到达该材料时的状态。

#### 面板组件

```
┌────────────────────────────────────┐
│  Intersections                     │
├────────────────────────────────────┤
│ [Find Intersections]               │
├────────────────────────────────────┤
│ Selected Intersection:             │
│ ┌────────────────────────────────┐ │
│ │ Up:  2.45 km/s                 │ │
│ │ P:   0.85 Mbar                │ │
│ │ CR:  1.44                      │ │
│ └────────────────────────────────┘ │
├────────────────────────────────────┤
│ ┌────────────────────────────────┐ │
│ │ Up      P       Curve1 Curve2  │ │
│ │ 2.45   0.85    Al_371  RL_1    │ │
│ │ 3.12   1.23    Quartz  RL_2    │ │
│ │ ...                            │ │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

#### 查找交点步骤

1. **准备数据**
   - 确保已勾选至少一个材料
   - 确保已添加至少一条雷利线

2. **查找交点**
   - 点击 **Find Intersections** 按钮
   - 系统自动计算所有交点
   - 交点显示在表格中

3. **选择交点**
   - 方法一：点击图表中的交点标记
   - 方法二：点击表格中的某一行
   - 选中的交点会高亮显示

4. **查看信息**
   - 面板顶部显示选中交点的详细信息
   - 包括：Up、P、CR（压缩比）

#### 交点计算原理

系统使用**符号变化检测**算法查找交点：

1. 对于每条曲线与每条雷利线
2. 计算 P_curve(uₚ) - P_Rayleigh(uₚ)
3. 查找符号变化的区间
4. 使用线性插值精确定位交点

#### 交点信息说明

| 字段 | 说明 | 单位 |
|------|------|------|
| **Up** | 粒子速度 | km/s |
| **P** | 压力 | Mbar |
| **CR** | 压缩比 | 无量纲 |
| **Curve1** | 第一条曲线 ID | - |
| **Curve2** | 第二条曲线 ID | - |

#### 压缩比计算

选择交点后，压缩比自动计算：

**CR = D / (D - uₚ)**

其中 D 是雷利线的冲击波速度，uₚ 是交点的粒子速度。

**注意**：当 uₚ 接近 D 时，CR 会变得很大，这是正常的物理现象（接近极限压缩）。

### 反射 Hugoniot 面板

**位置**: 左侧下部

#### 功能概述

当冲击波从高阻抗材料进入低阻抗材料时，会产生反射波。反射 Hugoniot 描述反射后的材料状态。

#### 面板组件

```
┌────────────────────────────────────┐
│  Reflected Hugoniot                │
├────────────────────────────────────┤
│ Selected Intersection:             │
│ Up: 2.45 km/s  P: 0.85 Mbar        │
│                                    │
│ Curve: [Aluminum (SESAME 3717) ▼]  │
│                                    │
│ [Add Reflected Curve]              │
│ [Clear] [Clear All]                │
├────────────────────────────────────┤
│ ☐ Al_3717 reflected, center: Al_371│
│ ☐ Quartz reflected, center: Quartz │
│ ...                                │
└────────────────────────────────────┘
```

#### 创建反射 Hugoniot 步骤

1. **选择交点**（必需）
   - 在交点面板或图表中选择交点
   - 交点信息会显示在面板顶部

2. **选择材料**
   - 从下拉菜单选择要反射的材料
   - 通常选择交点中的材料之一

3. **添加反射曲线**
   - 点击 **Add Reflected Curve** 按钮
   - 反射曲线显示在图表中（点划线）
   - 颜色与原曲线相同

#### 反射原理

对于从交点 (uₚ,center, P,center) 反射的 Hugoniot：

**uₚ' = 2 × uₚ,center - uₚ**

其中：
- uₚ,center：交点的粒子速度
- uₚ：原始曲线上的粒子速度
- uₚ'：反射曲线上的粒子速度

#### 反射曲线属性

| 属性 | 说明 |
|------|------|

## 物理模型

### 雷利线方程

雷利线描述冲击波前沿的状态关系：

**P = ρ₀ × uₚ × D × 0.01**

**推导过程**：

根据质量守恒和动量守恒：
- 质量守恒：ρ₀ × D = ρ × (D - uₚ)
- 动量守恒：P = ρ₀ × D × uₚ

单位转换：
- D, uₚ：km/s → cm/s (× 1e5)
- ρ₀：g/cm³
- P：dyne/cm² → Mbar (÷ 1e12)

综合：
```
P (Mbar) = ρ₀ (g/cm³) × D (km/s) × uₚ (km/s) × 0.01
```

**物理意义**：
- 对于固定的 D 和 ρ₀，P 与 uₚ 成线性关系
- 雷利线斜率：dP/duₚ = ρ₀ × D × 0.01
- 通过原点 (uₚ = 0, P = 0)

### 压缩比计算

压缩比是冲击压缩后密度与初始密度的比值：

**CR = ρ / ρ₀ = D / (D - uₚ)**

**推导**：

从质量守恒：
```
ρ₀ × D = ρ × (D - uₚ)
ρ / ρ₀ = D / (D - uₚ)
```

**物理意义**：
- CR ≥ 1（冲击压缩总是增加密度）
- 当 uₚ → D 时，CR → ∞（极限压缩）
- 典型金属的 CR 范围：1.0 - 4.0

### 反射 Hugoniot

当冲击波从高阻抗材料进入低阻抗材料时：

**uₚ' = 2 × uₚ,center - uₚ**

其中：
- uₚ,center：交点（冲击到达界面）的粒子速度
- uₚ：原始曲线上的粒子速度
- uₚ'：反射曲线上的粒子速度

**物理意义**：
- 反射曲线是原始曲线关于 uₚ = uₚ,center 的镜像
- 交点处 uₚ' = uₚ,center（连续性）
- 自由表面反射：uₚ,FS = 2 × uₚ,center

### 单位转换表

| 物理量 | 符号 | 常用单位 | SI 单位 | 转换关系 |
|--------|------|----------|---------|----------|
| **压力** | P | Mbar | Pa | 1 Mbar = 100 GPa = 10¹¹ Pa |
| **粒子速度** | uₚ | km/s | m/s | 1 km/s = 1000 m/s |
| **冲击波速度** | D, Us | km/s | m/s | 1 km/s = 1000 m/s |
| **密度** | ρ | g/cm³ | kg/m³ | 1 g/cm³ = 1000 kg/m³ |
| **温度** | T | eV | K | 1 eV ≈ 11605 K |
| **内能** | E | MJ/g | J/kg | 1 MJ/g = 10⁶ J/kg |

**实用转换**：
- 1 Mbar = 100 GPa
- 1 GPa = 10 kbar
- 1 kbar = 0.1 GPa

## 常见问题

### Q1: 为什么我的材料没有显示在列表中？

**可能原因和解决方案**：

1. **文件位置错误**
   - 确保文件在 `im_app/standard_library/materials/` 目录下
   - 检查文件扩展名（`.txt` 或 `.hug`）

2. **文件格式错误**
   - 使用 **Validate File** 检查格式
   - 确保有 7 行注释头（标准格式）
   - 检查列名是否匹配

3. **未刷新**
   - 点击 **Refresh** 按钮重新加载
   - 重启应用程序

4. **metadata.json 未更新**
   - 检查 `metadata.json` 是否包含该材料
   - 手动添加或使用 Refresh 自动添加

### Q2: 图表显示为水平线是怎么回事？

**原因**：数据单位转换错误

**解决方案**：

1. **检查数据单位**
   - 确认压力列是 Mbar，不是 GPa 或 Pa
   - 确认速度列是 km/s

2. **如果是 FEOS .hug 格式**
   - 检查文件头部注释是否正确
   - P 列应该已是 Mbar 单位
   - Us, Up 列应该已是 km/s 单位

3. **验证文件**
   - 使用 **Validate File** 功能
   - 查看数据范围是否合理

### Q3: 如何导出高分辨率图表用于论文？

**步骤**：

1. 在图表区域点击 **Export** 按钮
2. 选择格式：
   - **PNG**：位图，适合插入文档
   - **PDF**：矢量图，适合论文投稿
3. 选择分辨率（默认 300 DPI）
4. 保存文件

**建议**：
- 论文投稿：使用 PDF 格式
- 演示文稿：使用 PNG（300 DPI）
- 网络发布：使用 PNG（150 DPI）

### Q4: 参考曲线和标准材料有什么区别？

| 特性 | 标准材料 | 参考曲线 |
|------|----------|----------|
| **格式** | 7 行注释 + 数据 | 简化 CSV |
| **必需列** | Up, Us, P, rho, compression | Up, P |
| **元数据** | 完整（名称、来源、密度） | 简化（仅名称） |
| **用途** | 标准状态方程 | 实验数据、对比 |

**选择建议**：
- 完整的 EOS 数据 → 标准材料
- 实验测量数据 → 参考曲线
- 模拟结果对比 → 参考曲线

### Q5: 压缩比计算结果异常大怎么办？

**检查项**：

1. **冲击波速度 D 是否正确**
   - 确认 D 的单位是 km/s
   - 检查雷利线参数

2. **交点粒子速度 up 是否合理**
   - 查看 up 的值
   - 确认单位是 km/s

3. **物理合理性**
   - 当 up 接近 D 时，CR 会很大（正常）
   - 检查是否接近极限压缩

**典型值参考**：
- 金属：CR ≈ 1.0 - 4.0
- 极限压缩：CR → ∞（理论上）

### Q6: 支持哪些文件编码？

**推荐编码**：UTF-8

**问题**：
- 中文或特殊字符显示为乱码
- 注释行无法正确解析

**解决方案**：
1. 使用文本编辑器（如 Notepad++）打开文件
2. 转换编码为 UTF-8
3. 保存文件
4. 重新加载

**支持的编码**：
- UTF-8（推荐）
- UTF-8 with BOM
- ASCII

### Q7: 如何批量转换数据文件？

**方法一：使用转换脚本**

```bash
python scripts/convert_to_standard.py --input raw_data.csv --output materials/Al_new.txt
```

**方法二：使用 Python**

```python
from im_app.core.data_converter import convert_to_standard

convert_to_standard(
    input_path="raw_data.csv",
    output_path="materials/Al_new.txt",
    material_name="Aluminum",
    reference="Experimental 2024",
    rho0=2.7
)
```

**方法三：使用材料向导**
- 支持从剪贴板粘贴
- 支持从文件加载
- 自动格式化输出

### Q8: 图例显示不完整或重叠怎么办？

**解决方案**：

1. **手动调整**
   - 点击图表中的图例
   - 拖动到合适位置

2. **减少材料数量**
   - 取消勾选部分材料
   - 分批分析

3. **使用缩写**
   - 编辑材料名称（修改 metadata.json）
   - 使用简称（如 "Al" 而非 "Aluminum"）

4. **调整字体大小**
   - 编辑 `plotter.py` 中的 `fontsize` 参数
   - 重启应用
